# Kigali Clinic - Quiz 2: Completing the Backend

This repository contains the completed Spring Boot backend for **Quiz 2** of Web Technology and Internet at AUCA.

It extends the Quiz 1 clinic system with:

- Doctor and office management
- Appointment business rules
- Prescription management
- Doctor agenda and clinic dashboard
- Bonus reports

## Run

```powershell
.\mvnw.cmd spring-boot:run
```

API base URL: `http://localhost:8084`

Postman collection: `clinic-quiz2.postman_collection.json`

Seed data: `seed-data.sql`
